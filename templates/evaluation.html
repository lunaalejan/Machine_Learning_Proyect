CRISP-ML · PHASE 05

Model Evaluation

This stage evaluates the performance of the Machine Learning model developed for the Predictive Maintenance System. It examines classification metrics, prediction errors, model generalization, and the ability to identify industrial equipment failures.

01. Evaluation Overview

Purpose of Model Evaluation

Model Evaluation determines how effectively the trained classification model predicts machine failures using equipment operating conditions. The evaluation process compares predicted values with the actual target values from observations that were not used during model training. This stage is particularly important because the system must identify potential failure cases and provide reliable information to support maintenance decisions.

Evaluation Objective

Assess the predictive performance of the Random Forest classifier, identify its strengths and limitations, and determine whether its results support its use within the application.

02. Evaluation Strategy

Testing Process

The evaluation process uses a testing subset separated from the training data. The dataset was divided using an 80% training and 20% testing split, with random_state=42 and stratification to preserve the target class distribution.

  • Load the trained classification model.
  • Generate predictions using the testing data.
  • Compare predictions with actual target values.
  • Calculate classification performance metrics.
  • Analyze false positives and false negatives.
  • Document the results and limitations.

05. ROC Curve and AUC

Model Discrimination Ability

The Receiver Operating Characteristic (ROC) curve illustrates the relationship between the True Positive Rate and the False Positive Rate at different classification thresholds. The Area Under the Curve (AUC) provides an overall measure of the model's ability to distinguish between failure and non-failure observations. The evaluated model achieved a ROC-AUC score of 0.9658.

06. Model Performance Analysis

Interpretation of Results

The Random Forest model achieved an Accuracy of 97.15% and a ROC-AUC of 96.58%, indicating strong overall classification performance. However, the dataset contains an imbalance between non-failure and failure observations. There are 9,661 non-failure records and only 339 failure records in the complete dataset. Therefore, Accuracy alone is not sufficient to assess the model's performance. Recall, Precision, and F1-score are especially important for understanding the model's ability to detect machine failures.

  • The model correctly identified 52 actual machine failures.
  • The model missed 16 actual failure cases.
  • The model generated 41 false positive alerts.
  • Recall of 76.47% shows that the model detected approximately three quarters of the actual failures.
  • Precision of 55.91% indicates that false alarms remain an important limitation.

07. Overfitting and Generalization

Overfitting

Overfitting occurs when a model learns patterns specific to the training data but performs poorly on unseen observations. A comparison between training and testing performance is necessary to determine whether overfitting is present.

Generalization

Generalization describes the model's ability to maintain predictive performance when analyzing observations that were not included during training. The testing subset provides an initial measure of this ability.

Evaluation limitation: Training metrics and cross-validation results have not yet been calculated. Therefore, overfitting and generalization require additional verification.

08. Final Model Assessment

Model Selection and Reliability

The Random Forest classifier achieved promising results on the testing dataset, with 97.15% Accuracy and 96.58% ROC-AUC. The model identified 52 of the 68 actual machine failures. However, 16 failures remained undetected and 41 false positive predictions were generated. These results demonstrate the model's potential for predictive maintenance, while also highlighting the importance of improving failure detection and reducing false alarms. The model should be considered a decision support tool rather than a replacement for professional maintenance inspections.

Additional evidence: The project instructions also request model comparison, cross-validation where applicable, and feedback from someone with industrial maintenance knowledge. These elements must be documented only after they have actually been performed.

Phase Conclusion

The Model Evaluation stage measured the predictive performance of the Random Forest classifier using 2,000 testing observations. The model achieved 97.15% Accuracy, 55.91% Precision, 76.47% Recall, 64.60% F1-score, and 96.58% ROC-AUC. The confusion matrix and ROC curve provide visual evidence of the evaluation results. Although the model demonstrates promising classification ability, false negatives and false positives remain important considerations for predictive maintenance. The next stage, Model Deployment, focuses on integrating the evaluated model into the Flask application and making its prediction functionality available to users.
