Data Understanding

This stage focuses on understanding the data used in the Predictive Maintenance System. It includes the identification of the data source, dataset structure, relevant variables, initial exploration, and potential data quality limitations.

01. Data Source

AI4I 2020 Predictive Maintenance Dataset

The project uses the AI4I 2020 Predictive Maintenance Dataset, a publicly available dataset designed for predictive maintenance research. It contains simulated industrial equipment operating information and failure labels. The dataset provides variables related to temperature, rotational speed, torque, and tool wear, which can be used to study patterns associated with machine failure. This dataset serves as the foundation for developing and evaluating the Machine Learning component of the Predictive Maintenance System.

Data source: AI4I 2020 Predictive Maintenance Dataset. The project uses the file ai4i2020.csv. The dataset is used for academic development and experimentation, not as a direct representation of every real industrial environment.

02. Dataset Characteristics

10,000 Records / observations
14 Original columns
5 Failure mode indicators

Dataset Structure

Each record represents an observation of an industrial machine. The dataset includes identification fields, machine characteristics, operating measurements, a general machine failure indicator, and specific failure mode indicators. These variables allow the analysis of equipment operating conditions and their relationship with failure events.

04. Variables Used by the Prediction Model

Selected Input Features

The prediction module receives six input variables. These variables describe the machine type and its operating conditions. The model uses them to estimate the probability of a machine failure.

Input variable Unit / Format Purpose
Type L / M / H Identifies the machine variant.
Air temperature Kelvin (K) Describes ambient temperature.
Process temperature Kelvin (K) Describes process temperature.
Rotational speed Revolutions per minute (rpm) Describes machine rotation.
Torque Newton meters (Nm) Describes applied rotational force.
Tool wear Minutes (min) Describes accumulated tool wear.

Target variable: Machine failure. This variable represents the outcome the model is designed to predict. It is not entered as a prediction input.

05. Initial Data Exploration

Exploratory Data Analysis (EDA)

Initial data exploration is necessary to understand the distribution of the variables, identify patterns, examine relationships between measurements, and detect possible data quality problems before model development. The exploration process should include the following analyses:

  • Examine the distribution of machine failures and non-failures.
  • Analyze the distribution of air and process temperatures.
  • Examine rotational speed and torque values.
  • Analyze the distribution of tool wear.
  • Explore relationships between operating variables and machine failure.
  • Identify possible class imbalance in the target variable.

Failure Distribution

A comparison between failure and non-failure observations helps identify whether the target classes are balanced or imbalanced.

Operating Variables

Temperature, rotational speed, torque, and tool wear distributions help characterize the operating conditions represented in the dataset.

06. Data Quality Assessment

Data Quality Checks

Before using the dataset for model development, its quality must be examined to identify possible inconsistencies that could affect the results. The following checks are part of the analysis:

Quality check Purpose Evidence required
Missing values Identify incomplete observations. Null-value count.
Duplicate records Identify repeated observations. Duplicate count.
Data types Verify numerical and categorical formats. Column data types.
Value ranges Identify unusual or invalid values. Descriptive statistics.
Target distribution Identify possible class imbalance. Class frequencies.

07. Data Limitations

Dataset Considerations

  • The dataset is based on simulated industrial operating conditions.
  • Its observations may not represent all types of real industrial equipment.
  • The failure patterns included in the dataset do not cover every possible real-world failure.
  • The predictive model's performance depends on the quality and representativeness of the available data.
  • Additional testing with real operational data is necessary before applying the model in a production environment.

Phase Conclusion

The Data Understanding stage establishes the characteristics, structure, and limitations of the AI4I 2020 Predictive Maintenance Dataset. It identifies the variables required by the prediction module and defines the exploratory and quality checks needed before model development. The information obtained in this stage provides the foundation for the next step: Data Engineering, where the dataset will be cleaned, transformed, and prepared for Machine Learning training.
