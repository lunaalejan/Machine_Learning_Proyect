CRISP-ML · PHASE 01

Business Understanding

This stage defines the business problem, the project objectives, the stakeholders, and the expected value of developing a Machine Learning solution for predictive maintenance in industrial equipment.

01. Project Context

Project Overview

Predictive Maintenance System is a web-based application designed to support industrial maintenance activities through Machine Learning techniques. The project uses equipment operating variables to estimate the possibility of machine failure. The system integrates a predictive model developed in Python with a Flask application, allowing users to register equipment, manage maintenance records, review alerts, and obtain failure predictions.

Industrial Context

Industrial equipment operates under different conditions involving temperature, rotational speed, torque, and component wear. Changes in these operating conditions may be associated with equipment failures. Unexpected failures can interrupt production processes, increase maintenance expenses, and affect operational efficiency. For this reason, predictive maintenance represents an opportunity to use equipment data to support more informed maintenance decisions.

02. Business Problem

Problem Statement

Industrial maintenance teams may face difficulties identifying potential equipment failures before they occur. When maintenance activities depend mainly on fixed schedules or responses after a failure, equipment problems may remain undetected until they affect operations. The project addresses this challenge by developing a data-driven system capable of analyzing operating conditions and estimating the likelihood of machine failure.

Business Need

Provide a technological tool that helps maintenance personnel identify possible failure risks, review equipment information, and support maintenance planning using Machine Learning predictions.

03. Project Objectives

General Objective

Develop a predictive maintenance system that integrates Machine Learning and web technologies to estimate potential industrial equipment failures based on operating data and support maintenance decision-making.

Specific Objectives

  • Analyze the AI4I 2020 Predictive Maintenance Dataset.
  • Identify relevant variables associated with machine failure.
  • Develop and train a classification model.
  • Evaluate model performance using appropriate classification metrics.
  • Integrate the predictive model into a Flask web application.
  • Provide equipment management, maintenance records, and alert functionalities.

04. Machine Learning Objectives

Machine Learning Problem Definition

The Machine Learning component is formulated as a supervised binary classification problem. The model learns patterns from labeled equipment data and estimates whether a machine is likely to experience a failure under the provided operating conditions.

  • Learning approach: Supervised Learning.
  • Problem type: Binary Classification.
  • Target variable: Machine failure.
  • Positive class: Failure (1).
  • Negative class: No failure (0).
  • Selected algorithm: Random Forest, subject to evaluation and comparison with other classification algorithms.

05. Stakeholders and Beneficiaries

Stakeholder Role and Expected Benefit
Industrial Companies Obtain information that can support equipment maintenance planning and operational decisions.
Maintenance Technicians Review equipment conditions, maintenance records, alerts, and predicted failure risks.
Production Managers Use predictive information to support operational planning and maintenance coordination.
System Administrators Manage equipment information, system records, and application functionality.

06. Project Scope

Included in the Project

  • Analysis of the AI4I 2020 dataset.
  • Machine failure classification.
  • Random Forest predictive model.
  • Flask-based web application.
  • Equipment registration and management.
  • Maintenance record management.
  • Prediction and alert functionalities.

Outside the Current Scope

  • Direct connection to industrial sensors or physical IoT devices.
  • Automatic control of industrial machinery.
  • Guaranteed prevention of equipment failures.
  • Real-time industrial deployment validated in a production environment.

07. Risks and Limitations

Project Limitations

  • The predictive model is developed using the AI4I 2020 dataset, so its performance depends on the characteristics and representativeness of that dataset.
  • The dataset does not represent every industrial machine, operating environment, or failure scenario.
  • Predictions depend on the accuracy and validity of the operating values entered by the user.
  • Model predictions are estimates and should not replace professional technical inspections or maintenance decisions.
  • Additional validation with real industrial data is required before applying the model to different equipment or production environments.

08. Success Criteria

How Project Success Will Be Evaluated

The success of the project will be evaluated through the technical performance of the classification model and the correct integration of its functionalities into the web application.

  • The model can generate predictions using the selected input variables.
  • Model performance is evaluated using Accuracy, Precision, Recall, F1-score, and ROC-AUC.
  • The model demonstrates an adequate ability to identify failure cases, with particular attention to Recall.
  • The Flask application correctly integrates the prediction module.
  • Equipment, maintenance records, predictions, and alerts can be managed through the application.
  • The project documentation presents evidence and results obtained during development.

Phase Conclusion

The Business Understanding stage establishes the industrial problem, the expected value of the project, and the objectives of the predictive maintenance solution. It defines the direction of the Machine Learning development process and provides the foundation for the next stage: Data Understanding, where the AI4I 2020 dataset will be examined in detail to identify its structure, variables, characteristics, and limitations.
