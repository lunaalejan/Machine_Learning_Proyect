CRISP-ML · PHASE 03

Data Preparation

This stage describes the processes required to transform the AI4I 2020 dataset into a suitable format for Machine Learning. It covers data loading, cleaning, feature selection, transformation, target preparation, and dataset partitioning.

01. Data Preparation Overview

Purpose of Data Preparation

Data preparation is a fundamental stage in the development of the Predictive Maintenance System. Its purpose is to organize and transform the information collected in the AI4I 2020 dataset before using it to train the predictive model. This process helps ensure that the input variables have the appropriate structure and format, while reducing the possibility of errors and information leakage during model development.

Preparation Objective

Obtain a consistent dataset containing the relevant machine operating variables and the target variable Machine failure, ready for model training and performance evaluation.

02. Data Loading

Dataset Importation

The preparation process begins by loading the ai4i2020.csv file into the Python environment. The Pandas library can be used to read the CSV file and create a DataFrame, allowing the data to be inspected and manipulated. Initial inspection includes reviewing the first records, column names, data types, and dimensions of the dataset.

04. Feature Selection

Selection of Relevant Variables

Feature selection consists of identifying the variables that provide relevant information for predicting machine failure. The prediction module uses six input features corresponding to machine type and operating conditions. Identification fields and failure mode indicators are not included as prediction inputs in the described model interface.

Variable Role Reason
Type Input feature Machine variant.
Air temperature Input feature Operating temperature.
Process temperature Input feature Thermal operating condition.
Rotational speed Input feature Machine rotational behavior.
Torque Input feature Mechanical operating load.
Tool wear Input feature Accumulated tool wear.
Machine failure Target Outcome to predict.

Information leakage prevention: Failure mode indicators such as TWF, HDF, PWF, OSF, and RNF are not used as input features in the prediction interface. These variables describe failure information and could reveal information about the target if included improperly.

05. Data Transformation

Preparing Variables for the Model

Data transformation involves adapting the selected variables to the format expected by the Machine Learning algorithm. The machine Type variable is categorical and requires an appropriate numerical representation if the selected model implementation expects numerical inputs. The remaining operating measurements are numerical variables.

  • Verify that numerical measurements use appropriate numeric data types.
  • Encode the categorical Type variable using the same method applied during model training.
  • Preserve the original measurement units.
  • Apply the same transformations to training data and future prediction inputs.

Consistency requirement: The transformation used during training must be reproduced in the prediction module. Do not introduce scaling, encoding, or other transformations unless they are part of the actual training pipeline.

06. Target Variable Preparation

Machine Failure Classification

The target variable selected for the predictive model is Machine failure. It represents whether a machine failure occurred in the corresponding observation. The task is formulated as binary classification, where the model learns to distinguish between failure and non-failure cases.

Target value Class Meaning
0 No Failure No machine failure recorded.
1 Failure Machine failure recorded.

07. Training and Testing Split

Dataset Partitioning

The dataset should be divided into separate subsets to evaluate how well the model performs on observations that were not used during training. A training subset is used to fit the model, while a testing subset is reserved for the final evaluation of its predictive performance. The partitioning strategy, test proportion, random state, and stratification settings must match the actual training script.

  • Training set: used to learn patterns from the input variables.
  • Testing set: used to evaluate predictions on previously unseen observations.
  • Stratification: may be applied to preserve the target class proportions in both subsets.
  • Random state: used to make the split reproducible.

Evidence required: Document the actual number of training and testing observations, the split proportion, and the configuration used in the project's training script.

08. Preparation Summary

Stage Conclusion

The Data Preparation stage defines the operations required to convert the original AI4I 2020 dataset into a suitable structure for predictive modeling. It establishes the input features, target variable, data quality checks, transformation requirements, and training and testing partitioning strategy. Once these operations have been implemented and verified in the project's training pipeline, the prepared data can be used in the next stage: Model Engineering, where the classification algorithms are developed and trained.
